# bugvoid.github.io

Portfolio de Luan Castro Alves: **https://bugvoid.github.io**

HTML, CSS e JavaScript puros, sem build, publicados pelo GitHub Pages a partir da branch `main`.

- `index.html`: conteúdo
- `styles.css`: tema claro/escuro automático (`prefers-color-scheme`)
- `demo.js`: demo ao vivo que chama a API do [simulador de renda fixa](https://github.com/Bugvoid/simulador-renda-fixa). Defina `API_URL` com o `api_url` do Terraform.

```bash
python -m http.server 8000   # http://localhost:8000
node --test                  # testes da demo
```
